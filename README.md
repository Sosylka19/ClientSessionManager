```
_description_: клиент-серверное приложение, где сервер хранит в реестре каждый IP клиента, в свою очередь клиенты могут подключаться к серверу и слушать его команды

_stack:_ C++, boost::asio, Makefile
```

### Скачивание BOOST
```Windows```: 

``` terminal
make install_boost_win
```

```MacOS```: 

``` terminal
make install_boost_mac
```

### Сборка бинарников сервера и клиента, запуск сервера

```make``` - запустит сервер

```make test``` - запустит тесты
